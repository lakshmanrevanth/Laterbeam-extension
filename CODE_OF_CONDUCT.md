# Code of Conduct

CheckLater adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. By taking part in this project (issues, pull requests, discussions, reviews) you agree to follow it.

In short: be respectful, assume good faith, give and accept constructive feedback, and don't harass anyone.

## Enforcement

Report unacceptable behaviour to the maintainer, [@lakshmanrevanth](https://github.com/lakshmanrevanth):

- open an issue at <https://github.com/lakshmanrevanth/check-later-extension/issues> asking for a private contact, without details, or
- for anything sensitive, use the repository's private reporting channel described in [SECURITY.md](SECURITY.md).

Reports are handled confidentially. The maintainer may edit or remove comments, commits, issues and pull requests, and may block contributors who break the code of conduct, following the enforcement guidelines in the Covenant.
